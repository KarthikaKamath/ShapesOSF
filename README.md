This repository contains materials associated with CogSci paper submission "How do preverbal infants represent geometric shapes?" and is linked to OSF - https://osf.io/bp6wn/overview for transparency, reproducibility, and open access to data and materials.

The repository is organised into 2 main folders:
1. Data Analysis
   - Raw and processed data used in the analysis
   - R scripts for step-by-step data processing and analysis
2. Stimuli
   - Has sample stimulus images and videos for helping understand the study design better
   - For a full experiment design stimuli/code reach out to first or last author

Notes:
- Some stimuli may be partially shared due to copyright or ethical restrictions.
- Data have been anonymised to protect participant privacy.
- This repository is intended for academic and research use.

For questions or clarifications, please contact the authors via the information provided in the associated paper.
